# Менеджер задач

Лабораторная работа №3. Приложение из Л2 переписано на React и дополнено списками, подзадачами и маршрутизацией.

Стек: React 19, React Router, Vite, JavaScript, CSS.

[Макет To-Do List](https://www.figma.com/design/U09ssoBkhIpaSLmO5v0AQ7/To-Do-List-(Community))

## Запуск

Нужен Node.js 22.12 или новее.

```sh
npm install
npm run dev
```

Адрес приложения появится в терминале.

## Что работает

- Создание, переименование и удаление списков.
- Добавление, редактирование и удаление задач, отметка выполнения.
- Описание, время и подзадачи с прогрессом.
- Фильтры, поиск с задержкой 300 мс и счётчики активных задач.
- Светлая и тёмная темы.
- Сохранение в localStorage и перенос данных из Л2.
- Отдельные адреса списков и задач, обработка неизвестных страниц.

## Особенности

Отметка задачи не меняет отметки её подзадач. Поиск сбрасывается при смене списка, а фильтр хранится в URL. На телефоне списки открываются кнопкой меню, карточка задачи занимает основную область экрана. На широком экране карточка находится рядом со списком.

Изменения в карточке сохраняются кнопкой «Сохранить». При удалении списка удаляются и его задачи, поэтому сначала открывается подтверждение.

Данные хранятся только в текущем браузере. Перенос из Л2 работает, если обе версии открыты на одном адресе и порту. Начальная тема берётся из настроек системы, затем сохраняется выбор пользователя.

## Проверка и сборка

```sh
npm run lint
npm test
npm run build
npm run preview
```

Браузерные тесты:

```sh
npx playwright install chromium
npm run test:e2e
```

Для Vercel: команда сборки `npm run build`, папка результата `dist`. Прямые ссылки настроены в `vercel.json`.
