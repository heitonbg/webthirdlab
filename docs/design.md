# Палитра и адаптивность

Исходные токены перенесены из `secondlab/css/style.css`: фон `#1a1916`, карточка `#24221e`, текст `#e6d5b8`, оранжевый `#ff8303`, Courier New и радиус 4 px. По ссылке Figma инструмент чтения не получил доступ; основанием реализации послужило оформление уже выполненной Л2. Точное совпадение с недоступными экранами Figma не заявляется.

Тёмная тема сохраняет исходную палитру; приглушённый текст осветлён с `#8a7968` до `#bbaa92` ради контраста. Светлая тема развивает тот же набор тёплых оттенков: бумажные поверхности `#faf6ee` / `#fffdf8`, тёмно-коричневый текст `#29231c`, тёмный вариант оранжевого для ссылок `#a34d00`. На оранжевых кнопках используется тёмный текст `#1a1916`.

Минимальный контраст текста на трёх поверхностях (`bg`, `surface`, `surface-alt`), рассчитанный по относительной яркости sRGB:

| Роль | Светлая | Тёмная |
|---|---:|---:|
| Основной текст | 12.44:1 | 9.74:1 |
| Вторичный текст | 5.50:1 | 6.20:1 |
| Акцентный текст | 4.65:1 | 5.68:1 |
| Ошибка | 5.99:1 | 6.87:1 |

Все перечисленные сочетания выше 4.5:1. Проверка входит в браузерный тест и читает фактические CSS-переменные. Цвет не является единственным признаком состояния: выполненная задача имеет отметку и зачёркивание, фильтры — `aria-pressed`, ошибки — текст.

360 px: скрываемая панель в потоке, список или карточка на всю ширину основного содержимого. 768 px: постоянная боковая панель, карточка заменяет список. 1280 px: боковая панель, список и карточка рядом. Длинные названия переносятся; контроль отсутствия горизонтальной прокрутки выполняется автоматически.
